# Auditoria externa (Codex) — 23/09/2026 — veredito

Uma segunda IA (Codex) auditou a skill contra a documentação oficial. Cada achado foi conferido de novo antes de qualquer mudança. Este arquivo registra o que foi aceito, com qual evidência, e o que foi rejeitado.

## Aceitos e corrigidos

| # | Achado | Evidência conferida | Correção |
| --- | --- | --- | --- |
| 2 | Catálogo do Pinterest desatualizado | Tabela "Name in API / Name in Tag" em developers.pinterest.com (21 eventos, inclui `view_content`, `initiate_checkout`, `contact`, `schedule`, `start_trial`, `submit_application`) | Catálogo atualizado com nomes de tag em CamelCase e da API em snake_case |

| 6 | `anonymousId` sem ID Sync (Microsoft) | Guia da CAPI do UET | Limitação documentada com instrução do ID Sync |
| 7 | Limite de corpo lido depois do corpo inteiro | Inspeção | `Content-Length` checado antes, bytes reais depois |

| 18 | Token da Meta na query string | Precaução (backfill já usava corpo) | Token no corpo da requisição |
| Lacuna | `Purchase` repetido gerava `event_id` novo | Inspeção | `event_id` determinístico com `order_id` |
